# 💬 ویجت چت هوشمند (SmartChat)

ویجت چت و پشتیبانی فارسیِ راست‌چین — آماده‌ی **فروش به سایت‌ها**.
به **Gemini** متصل می‌شود، **اطلاعات سایت مشتری را خودکار استخراج** می‌کند و در همان لحظه به سؤال مشتری جواب می‌دهد (مثلاً برای لباس‌فروشی: «شومیز گل‌دار را بگیر، ۶۴۰ هزار تومان و برای مهمانی عالی است!»).

![طراحی مشابه نمونه ارسالی: هدر گرادیانی بنفش، جستجو، سوالات آماده، تب‌های خانه/پیام‌رسان/پایگاه دانش]

---

## ۱) اجرا (۳ دقیقه)

```bash
cd chat-widget
npm install
npm start
```

بعد این‌ها را باز کنید:

| آدرس | چیست؟ |
|---|---|
| `http://localhost:3000/demo` | دمو: فروشگاه لباس «بوتیک مد روز» + ویجت چت |
| `http://localhost:3000/widget.js` | فایل ویجتی که به مشتری می‌دهید |

> ⚙️ بدون کلید Gemini هم کار می‌کند (حالت نمایشی: نزدیک‌ترین اطلاعات سایت را برمی‌گرداند). با کلید، جواب‌ها واقعاً هوشمند می‌شوند.

## ۲) اتصال به Gemini

1. از [Google AI Studio](https://aistudio.google.com/apikey) کلید بسازید.
2. فایل `.env` را کنار `server.js` بسازید (نمونه: `.env.example`):

```env
GEMINI_API_KEY=کلید_شما
GEMINI_MODEL=gemini-2.5-flash
PORT=3000
```

3. سرور را دوباره اجرا کنید: `npm start`

## ۳) فروش به یک سایت (چرخه تحویل به مشتری)

**قدم اول — سایت مشتری را ثبت کنید:**

```bash
curl -X POST http://localhost:3000/api/sites \
  -H "Content-Type: application/json" \
  -d '{"id":"shopali","name":"فروشگاه علی","url":"https://shopali.ir","faqs":["ارسال چقدر طول می‌کشد؟","مرجوعی دارید؟"]}'
```

**قدم دوم — اطلاعات سایتش را استخراج کنید:**

```bash
curl -X POST http://localhost:3000/api/sites/shopali/scrape
```

ربات خودش صفحات سایت می‌خزد (تا ۸ صفحه)، محصولات `JSON-LD` فروشگاهی، توضیحات، قوانین ارسال و… را می‌شکافد و ذخیره می‌کند.

**قدم سوم — این یک خط کد را به مشتری بدهید تا در سایتش بگذارد:**

```html
<script src="https://YOUR-SERVER/widget.js" data-site="shopali"></script>
```

تمام! ویجت «سوالی دارید؟» **پایینِ سمت راستِ** سایتش ظاهر می‌شود و با اطلاعات همان سایت جواب می‌دهد.
ویجت خودش از روی آدرس اسکریپت، سرور را پیدا می‌کند — مشتری هیچ تنظیم دیگری لازم ندارد.

> 💡 اگر `data-site` را ندهید، ویجت خودش دامنه‌ی سایت را به‌عنوان شناسه می‌گیرد (مثلاً `shopali.ir`) — یعنی یک اسکریپتِ کاملاً یکسان را می‌توانی به همه بدهی.

## ۴) سفارشی‌سازی ویجت برای هر مشتری

| اتریبیوت | مثال | کار |
|---|---|---|
| `data-site` | `"shopali"` | شناسه سایت (اختیاری — پیش‌فرض: دامنه سایت) |
| `data-color` | `"#E11D48"` | رنگ برند مشتری |
| `data-position` | `"left"` | محل دکمه (پیش‌فرض **راست**) |
| `data-api` | `"https://api.site.com"` | آدرس سرور شما (اختیاری — خودکار) |

> ⚠️ نکته استقرار: سرور شما باید **HTTPS** داشته باشد، چون سایت‌های مشتری معمولاً HTTPS هستند و مرورگر درخواست به آدرس HTTP را بلاک می‌کند (مثلاً با Nginx + Let's Encrypt یا Railway/Render).

## ۵) APIها (برای پنل مدیریت‌تان)

| متد | مسیر | شرح |
|---|---|---|
| `POST` | `/api/sites` | ثبت سایت جدید |
| `POST` | `/api/sites/:id/scrape` | استخراج اطلاعات سایت |
| `POST` | `/api/sites/:id/knowledge` | افزودن دستی متن (کاتالوگ، قوانین) |
| `GET` | `/api/config/:id` | پیکربندی عمومی ویجت |
| `POST` | `/api/chat` | `{site, message, history[]}` → `{reply}` |

## ۶) ساختار پروژه

```
chat-widget/
├── widget.js      ← ویجت امبدشونده (محصول اصلی) — Shadow DOM، بدون تداخل با CSS سایت میزبان
├── server.js      ← API + خزنده سایت + اتصال Gemini + حافظه per-site
├── store.html     ← فروشگاه لباس نمونه (قالب)
├── demo.html      ← دمو آماده (ویجت داخلش تزریق شده)
└── data/          ← اطلاعات استخراج‌شده هر سایت (JSON)
```

## ۷) نکته‌های فروش 💼

- هر مشتری را با یک `data-site` جدا معرفی می‌کنید — چند فروشگاه روی یک سرور شما.
- رنگ، پیام خوش‌آمد و سوالات آماده برای هر مشتری جدا تنظیم می‌شود — «شخصی‌سازی شده» بفروشید.
- اگر سایت مشتری محصولاتش را با `schema.org/Product` خروجی بدهد (وردپرس/ووکامرس و شاپ‌سی‌اف自然地 دارند)، قیمت‌ها دقیق‌تر استخراج می‌شود.
- برای محصول: اشتراک ماهانه + هزینه راه‌اندازی اولیه پیشنهاد می‌شود. 😉
